# Tab Out

> [English](./README.md)

**管好你的标签页。**

Tab Out 是一款 Chrome 扩展，把新标签页替换成「所有已打开标签页」的仪表盘。标签页按域名分组，首页类网站（Gmail、X、LinkedIn 等）单独归到一组。关闭标签页时有爽快的音效与彩纸动画。

无服务器。无账号。无外部 API 调用。只是一个 Chrome 扩展。

## 功能

- **一眼看清所有标签页**：干净的网格布局，按域名分组
- **首页分组**：Gmail 收件箱、X 首页、YouTube、LinkedIn、GitHub 首页自动归到一张卡片
- **有腔调地关闭**：音效 + 彩纸爆破动画
- **重复检测**：同一页面打开两次时自动标记，一键清理
- **跨窗口跳转**：点击任意标签页直接跳过去，不新开标签页
- **稍后保存**：关闭前先把标签页加入清单
- **快速搜索**：内置搜索框，不离开新标签页即可查询
- **待办清单**：直接在新标签页上记下任务，和标签页一起保存在本地
- **黑夜 / 白天主题**：按时间段自动切换日夜模式，也可一键手动切换
- **自定义背景**：设置纯色背景、粘贴图片链接，或上传本地图片作为壁纸
- **本地端口分组**：在每个标签页旁显示端口号，方便区分你的开发项目
- **可展开分组**：默认显示前 8 个标签页，点击「+N 个」展开
- **100% 本地**：数据永不离开你的设备
- **纯 Chrome 扩展**：无服务器、无 Node.js、无 npm，加载扩展即可使用

## 手动安装

**1. 克隆仓库**

```bash
git clone https://github.com/sundoubleday/new-tab.git
```

**2. 加载 Chrome 扩展**

1. 打开 Chrome，访问 `chrome://extensions`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择克隆下来的仓库文件夹（里面含 `manifest.json`），或下载 ZIP 解压后的顶层文件夹

**3. 打开新标签页**

你就会看到 Tab Out。

## 工作原理

```
打开新标签页
  -> Tab Out 按域名分组显示已打开的标签页
  -> 首页类（Gmail、X 等）单独成组，置顶
  -> 点击任意标签页标题跳转过去
  -> 关闭用完的分组（音效 + 彩纸）
  -> 关闭前把标签页保存到清单
```

所有逻辑都在 Chrome 扩展里运行。无外部服务器、页面内容或保存的数据都不会离开你的机器——保存的标签页存在 `chrome.storage.local`。

> **隐私说明：** 默认情况下，仪表盘会从 `google.com/s2/favicons` 拉取网站图标（仅首次请求；成功获取的图标会作为 data URL 缓存在 `chrome.storage.local` 中，之后该域名不再回源 Google），显示字体来自 Google Fonts，因此你打开的域名列表会发给 Google。页面内容和已保存项不会发送。如需完全离线，可屏蔽这两个域名，或自托管字体/图标。

想调整哪些标签页算「首页」、或把多个域名合并成自定义分组？把 [`config.local.js.sample`](./config.local.js.sample) 复制为 `config.local.js`（已被 gitignore，不会提交），按示例修改即可。
